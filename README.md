# 💬 Chat App

SPA-приложение для обмена текстовыми сообщениями, реализованное на Angular.

---

## Демо

🔗 https://encors.github.io/chat/

---

## 🧩 Технологии

- **Angular 21**
- **RxJS**
- **PrimeNG**
- **Bootstrap 5**
- **SCSS**

---

## ✨ Основной функционал

- Авторизация пользователя с обработкой ошибок
- Обмен сообщениями в каналах
- Список каналов
- Участники канала
- Профиль пользователя
- Защита маршрутов
- Адаптивная верстка (1024px – 1980px)
